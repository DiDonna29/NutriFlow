# **App Name**: NutriFlow

## Core Features:

- Daily Meal Dashboard: Displays an overview of the user's daily meal structure, categorized into configurable sections (e.g., Breakfast, Lunch, Dinner, Snacks) using a card-based layout.
- Predefined Food Item Management: Allows users to select and assign recurring food items (e.g., Avena, Huevos, Kéfir) to their meal sections for quick logging and visualization.
- Bilingual Language Support: Provides a user interface with text available in both English and Spanish, utilizing React Context for seamless language switching.
- Theme Toggle: Implements a button to dynamically switch the application's visual theme between a predefined light mode and a dark mode by modifying CSS classes.
- Responsive Design: Ensures the application's layout and content adapt fluidly across various devices and screen sizes, from mobile to desktop.

## Style Guidelines:

- Light theme background: A soft, creamy pale green (#F9FBE7), chosen to evoke freshness and a connection to natural produce, promoting a clean visual experience.
- Light theme container/card background: Crisp white (#FFFFFF), providing clear separation for content cards and enhancing readability.
- Light theme text: A deep, rich forest green (#33691E), selected for optimal contrast and readability against the light background, complementing the natural palette.
- Light theme accent: A bright, vibrant leaf green (#8BC34A), used to highlight interactive elements, calls-to-action, and key information, bringing energy to the interface.
- Dark theme background: A very dark, earthy green-gray (#1A2016), creating a muted, calming presence that reduces eye strain in low-light environments.
- Dark theme container/card background: A slightly lighter dark green-gray (#242E1F), maintaining definition for content areas while adhering to the dark theme's depth.
- Dark theme text: A gentle, desaturated off-white (#DCE7D5), ensuring clear contrast and comfortable readability against the dark backgrounds.
- Dark theme accent: A luminous, vibrant green (#9CCC65), chosen to stand out effectively against the darker palette, drawing attention to important features.
- Body and headline font: 'Inter' (sans-serif) for its modern, machined, and highly readable qualities, ideal for presenting nutritional information clearly in a dashboard.
- Utilize clean, line-based illustrative icons for meal categories, the theme toggle, and the language switcher to maintain a contemporary and consistent visual language.
- A dynamic grid of card-based components for each meal, ensuring visual separation and scalability while prioritizing a responsive design that adapts to all screen sizes.
- Implement subtle fade-in and slide animations for card loading and seamless theme transitions, enhancing the overall fluidity and user experience of the dashboard.
